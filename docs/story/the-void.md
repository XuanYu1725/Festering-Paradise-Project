# 虚空

虚空是世界的一部分，与现世世界同在。在虚空内部，没有任何绝对的物理规律甚至时空结构，只有无尽的混沌和虚无。依赖虚空力量而生活的存在被称为“虚空生物”，它们的形态和能力各异，通常具有强大的力量和诡异的特性。

## 虚空的基本特性

虽然我们说虚空没有绝对的物理规律，这是相对于表象世界而言的。维持虚空存在的规律是存在的：

1. 虚空具有强烈的扩张性，内部的物理规律随时间不守恒，虚空生物的能力和形态也会不断演化。

2. 虚空力量不属于任何一位旧神，它是宇宙本源的存在。

3. 虚空能够摧毁物质形态，扭曲时空结构，但不至于摧毁它。

4. 虚空对现世的侵入主要靠虚空自身的演化，整体受魔力梯度影响。

## 有关虚空的常见现象

1. 物质进入虚空后，能量从各种方向被耗散掉，在经过足够长的时间后，它不再有能发射光子的能力，最终连质量也不再存在，最终化为虚无。

2. 能量守恒在极小尺度上仍然成立，因此虚空的边界是具有热量的，而内部是绝对的虚无。虚空的边界是一层温热有粘性的表面，在现世的层面上限制了虚空的扩张。

3. 虚空本身没有运动属性，也没有空间属性，没有自身的惯性系，移动的是虚空的入口。我们把虚空的入口看成虚空流体。虚空流体受限于表面无法迅速扩张，只能缓慢流动。

4. 虚空流体是可以结晶的，本质上是常规物质的结晶内分散了虚空的入口，视觉上是漆黑的，因为内部不存在任何反射或辐射现象，只有表面的常规物质具有微弱的反射。

## 关于虚空吞噬物质的理论

现世的绝大部分空间是真空的，虚空的确切边界在微观尺度上实际上是模糊的，由于真空内的量子涨落，我们可以观测到一些各向异性的异常能量耗散现象，这就是虚空的体现。在宏观尺度上，可以明显观测到一侧的能量耗散，这一侧就是虚空。经过长时间的能量耗散后，一侧不再能发射出光子，可以看到漆黑的宏观空间，这就是虚空流体。

可以看到虚空是一个不断演化和扩张的实体，不存在确切边界，在宏观可以观察到发育后的虚空流体，微观则是量子涨落引起的能量耗散现象。

对于一侧有虚空的空间，只依靠魔力梯度和量子涨落的演化十分慢，扩散得到虚空流体的时间可能超过太阳系的寿命，其主要演化方式是通过吞噬大质量分子来加速扩散。对于一个大质量分子，在内部出现异常的能量差后，分子可能会转换为一种不稳定的构型，从而导致分解，释放一部分能量。同时，分解后的物质一部分可能会进入虚空的一侧，与更多的虚空内物质接触和膨胀，从而导致能量快速耗散。但另一方面，另一侧的物质远离虚空，导致虚空的扩张速度被减缓，两者的共同作用导致了虚空的扩散速度被限制在一个可观测的范围内。

## 虚空生物

虚空生物主要有下面几种形式：

非常规物质的生命体：可能不属于这个宇宙，它们能够适应虚空的环境。

虚空本身：虚空本身可视为一个不断演化的生命体，它的各个部分可能有局部的未知特性，甚至可能具有某种程度的意识。

以虚空为能量源的生命体：这些生命是常规物质的生命体，但它们成功适应并利用了虚空。以虚空产生的能量差驱动生化反应，形成了独特的生命形式。这些生物因细胞内富集大量的虚空晶体而通常呈漆黑色，具有强大的力量和诡异的特性。
