# 史莱姆

## 演化历史

史莱姆是一个十分古老、原始的生命形式，与大部分生物越来越复杂的趋势不同，史莱姆通过简化自身的结构来适应环境，因此诞生了非常多样化的种类。史莱姆的起源可追溯到古老者时代，最初的史莱姆形式是由古老者创造的修格斯。这是一种强大，复杂的高级生命体，在修格斯反抗古老者后，一些修格斯在不同的环境中精简自身基因的表达，形成了以粘液质和多细胞融合为基础的史莱姆类群。

同时，史莱姆依旧继承了那套源自外神乌波萨斯拉的基因，因此虽然不表达，史莱姆的体内仍然蕴含着不断变异的力量。这就造成了史莱姆即使大幅削减了自己的基因，也仍然能从两个不同的类群在同一个新的环境中诞生相似甚至相同的史莱姆种类。即，每个类群中的史莱姆都有进一步演化的潜力。

## 特性

史莱姆以粘液质和多细胞融合为基础，其表达系统和基因副本弥漫于整个身体，进食方式类似于单细胞胞吞。

由于史莱姆的这个基本特性，我们可以将整个史莱姆视作一个巨大的细胞，有特化的膜系统和细胞器系统。身体的各个部分都拥有高度的相似性，造成一种既简单又复杂的生物结构。不同的史莱姆个体甚至能够通过融合来形成更大的个体，或者分裂成更小的个体，这种能力使得史莱姆在适应环境和生存方面具有极大的灵活性。

## 常见的生态位

在平原上，最常见的史莱姆类型是各种颜色的 **普通史莱姆**（因为人类最先发现这一种），它们以植物和小型动物为食，通常在夜间活动，白天则躲藏在阴凉的地方，其颜色主要靠饮食结构决定，因此同一个个体的颜色会随着时间发生变化。这些史莱姆的表面柔软，内部充满了粘液质，能够通过分泌消化酶来分解食物，并通过吸收营养来维持生命。它们的身体结构非常简单，没有复杂的器官系统，但却能够通过不断地分裂和融合来适应环境的变化。

在山地和森林等更危险的环境中，可能会出现表面硬化的 **硬化史莱姆** 或者表面尖锐的 **尖刺史莱姆**，它们通过强化身体表面来保护自己免受捕食者的攻击。这些史莱姆通常具有更强的攻击性和防御能力，能够通过分泌特殊的化学物质来抵御敌人，或者通过快速移动来逃避危险。

在峡谷和洞穴等高低落差大的环境中，可能会出现具有强大攀爬能力的 **攀爬史莱姆**，它们能够通过分泌粘液来附着在垂直的表面上，并通过不断地分裂和融合来适应不同的环境条件。这些史莱姆通常具有更强的适应能力和生存能力，能够在恶劣的环境中生存下来。或者能够滑翔的 **飞行史莱姆**，它们通过灵活且强韧的形变能力将自己改造成具有飞行能力的形态，能够在空中滑翔或者短暂飞行，以逃避捕食者或者寻找食物。这些史莱姆通常具有更强的适应能力和生存能力，能够在恶劣的环境中生存下来。

在水中也有特化氧气呼吸系统的 **水生史莱姆** 或 **海洋史莱姆**，前一种能够更加高效地从水中提取氧气，而后一种是完全的水下生物，依靠水呼吸。

在琉璃幻境甚至虚空等特别的生态中，也有对应的史莱姆种类。
