# 秘密页面

恭喜你发现了这个秘密页面！

这里隐藏着吉祥物 Kleio Aotalia 的相关信息。

![Kleio](resources/profile/Kleio.png)

Kleio Aotalia 是溃烂幻界企划的吉祥物，这个形象结合了主策划轩宇1725的个人创伤经历、执念和思考。

在主策划的高中时期，曾一度陷入一种不太妙的精神状态，并伴随着众多痛苦或诡异的梦境。其中一个令人恐惧也后怕的梦境体验中出现了 Kleio Aotalia 的原型形象。最初只是一个扎麻花辫的金发黄瞳女孩（伴随着一些血腥的演出）。后来，她的金发黄瞳形象被保留，令人恐惧的部分则内化为该角色在剧情中的核心设定。

最开始这名角色的核心名称被定为 AOTA，是 Aspect of the Azathoth 的缩写。这名称的由来很明显，这是由主策划的梦境体验中诞生的角色，他也感受到在梦中自己会受到蒙蔽。因此 AOTA 是阿撒托斯的人类化身，具有内在的特殊性的同时，在扮演人类的过程中也受到自己的蒙蔽，认为自己是一个普通人类女孩。后来为了让这个角色更具个性和辨识度，主策划又为她取了一个名字 Kleio，这个名字的由来是希腊神话中的缪斯女神之一，掌管历史和史诗的缪斯女神克莱奥（Clio）。因此这个角色的全名就定为 Kleio Aotalia，中文写作柯莱·奥塔莉娅。

最开始其作为一个被高级学者们驱逐排斥的普通女孩，主角则在不明真相的情况下就做出帮助她或举报她的选择（溃烂幻界最开始的一个选择一套剧情的妄想），在后续的讨论中，我们决定让她成为一个更加矛盾性的存在：将其作为科恩国家教廷的圣女，表面上是崇拜秩序之神的神职人员，其真身却是最为混沌的存在，并将这个教廷命名为月光教廷。

如今，Kleio Aotalia 已成为溃烂幻界企划的象征，其精神与整个项目的世界观紧密相连，作为克苏鲁世界观和原创内容的最重要纽带。
