# 溃烂幻界企划介绍

溃烂幻界企划是一个克苏鲁背景的奇幻架空世界观，融合了克苏鲁体系中的未知恐惧和原创奇幻元素。该企划旨在通过丰富的设定构建一个真实、自洽的奇幻世界。

溃烂幻界发起于 2021 年末，至今已经发展成为一个包含丰富设定、正传故事和衍生桌游的完整企划。

本站点用于记录和展示该企划的设定、故事以及相关衍生作品。所有内容采用 **GNU GENERAL PUBLIC LICENSE** 许可。

除原始设定外，该企划包含基于这些设定的正传故事和衍生桌游（《世界树迷宫》）。

## 正传故事

正传故事是基于溃烂幻界企划的核心设定创作的主要叙事内容，讲述了在这个奇幻世界中发生的关键事件和人物经历。正传故事计划由多部作品构成，每一部作品都是对整个世界设定的演绎和叙事艺术的体现。

目前，正传第一部《溃烂幻界：天使的邪典》正在创作中，预计将于 2027 年发布。

## 衍生桌游

衍生桌游是独立于正传叙事以外的，基于设定集创作的桌面游戏作品。它们旨在通过互动和策略玩法让玩家更深入地体验溃烂幻界的世界观和故事背景。衍生桌游的每一部作品都是独立的，不相互关联。

目前，第一部衍生桌游《世界树迷宫》正在开发中，预计将于 2026 年发布第一版。
