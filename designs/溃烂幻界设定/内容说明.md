# 战斗系统的说明:

本游戏核心是法术战斗，但同时提供了多种其他的武器选择。
武器的强度主要取决于武器的特殊效果。下面提供了常规武器的模版。

==========

模板：锤
普通攻击（LC）：对攻击的单位造成近战伤害。可以破甲。
主动技能（若有）（F）
重击（被动）：速度超过阈值后，命中的敌人受到与下落速度成正比的暴击伤害。可以破甲。
强力攻击（RC）：全力一击，造成暴击伤害和击退，进入硬冷却

破甲后锤类武器会强行进入硬冷却，硬冷却时长是武器的属性
锤类武器的暴击伤害具有溅射效果

==========

模板：法具
主动技能（若有）（F）
普通攻击（HOLD_RC）：释放法具中的多个法术
精确攻击（Q-NUM）：选择法具中的具体法术
凝聚：（HOLD_SHIFT）：预先消耗一定魔力强化下一个法术
弥散：（被动）未命中的法术将会为周围的施法单位补充70%*(1-魔力凝聚乘数)于本次攻击的魔力，命中的法术将会为施法者回复5%*魔力回收乘数于本次攻击的魔力

==========

模板：剑
普通攻击：（LC）对目标造成近战伤害，0.7s*攻击速度乘数内不可使用剑技
主动技能（若有）（F）
剑技-横向劈砍（A/W-LC）
剑技-纵向劈砍（SPACE-LC）
剑技-上挑（Shift-SPACE-LC）
剑技-突刺（Shift+Q）
格挡：（RC）使用瞬间内如果在前方接受可格挡伤害则成功，自己不会受到伤害并在重置剑技cd：并将普通攻击替换为弹反
弹反：前方扇形区域造成一次在暴击基础上*1.5的伤害，判定为使用一次剑技

剑技若命中，其他剑技的cd变为0.4s*攻击速度乘数，否则0.7s*攻击速度乘数内不可使用剑技，该剑技cd设为0.7s*攻击速度乘数

==================

模板：弓
主动技能（若有）（F）
蓄力（HOLD_RC）：按住右键进行蓄力，伤害根据蓄力时间、武器伤害、弹药伤害共同决定，命中后连续命中层数+1。
连射（被动）：蓄力计时器根据连续命中层数加快。
多重射击（LC）：蓄力满后可以按下左键增加装填弹药量，初始最多装填3个弹药，装填满后左键为微调弹道角度。松开时若没有按下Shift，则按照弹道射出弹药。若按下Shift，则以当前蓄力时间的两倍速度间隙自动射出后续的弹药。直到全部射出前所有弓无法使用，并进入1s*攻击速度乘数的冷却。

只要有一发弹药未射中都会重置连续命中层数

==========

对于法术设计，需要设计一系列法术，它们可以直接推动游戏进程，比如开启机关、摧毁路障，在流程中，玩家一定要得到这些每一组法术中的至少一个。同时，需要设计大量的攻击类和增益类法术，他们强度相似，演出效果不同，玩家凭自己喜好进行搭配。

法术可以与其他类型的武器结合，而这个结合会影响武器特性的表现。每种结合还需独立设计，不由程序生成。在本游戏中，可能还会出现更多的法术结合。

# 故事线说明：

按照区域来分，玩家正常探索的区域主要是：（名称后续议定）

1. 初始山洞区域：包括一整个山地区域，初始山洞只能通向开局的城镇，其他部分的探索安排在后期的重返，至于玩家看不看得出来这和初始山洞是同一片区域就看造化了。山洞中玩家要凭直觉捡起自己的第一把武器，进行第一场战斗，玩家要学会基本的战斗和采集操作，以及暗示可以利用环境击败怪物。
2. 平原区域：在这里会放一些初始的npc引导，再次帮助玩家熟悉操作。但要注意信息差的营造，npc不一定会提供绝对正确的信息，但在前期这些信息不会有大的错误。以及最开始的大地图景色展示，通过地图设计将玩家引导向唯一的道路，通往城镇。
3. 城镇-科恩首都：科恩是游戏中五大国中最大的国家（还包含一些小国，会在续作中补充），历史上以军事取胜，夺得大量土地。有冒险者协会等经典的机构，还有各种法术/药剂的研究机构，研究世界观介绍中介绍过的科学原理（玩家在后期掌握的知识可能超过这些机构）。玩家在城镇中可随着流程的推进，从npc处获取不同的武器，学习新的法术、配方等。
4. 迷雾森林区域：在迷雾森林区域，会周期性地泛起迷雾，生成包括骷髅、腐尸之类的不死族，也是玩家第一次遇到这种特殊种族（在设定上，不死族都是靠外神邪魔之主的控制的）。在正常周期内，主要生成史莱姆和动物类的低级魔物。玩家在前期熟悉故事的期间主要就在首都和森林中往返。区域中有一个非主线BOSS可以击败，获取亡灵相关的武器和法术。（在后期这个区域会转变为血雾之森，难度加剧）
5. 风之谷区域：主角正式开启冒险的第一个具有挑战性的区域，在这里玩家会第一次遇到精英怪的存在。也会出现一些环境特化的魔物。玩家也会遇到一些冒险者在这片区域谋生。可以和他们交流见闻。区域会有一个主线BOSS，但不是章节特殊BOSS。击败后获得自然系的法术。
6. 在这里可结束第一个原型，玩家探索风之谷，击败boss后返回城镇，会被委托一个特殊任务，从“叛逃者”手中夺取重要法典。这是第一章的特殊BOSS。后续的剧情是玩家重新返回初始的山地区域，跋山涉水到达“叛逃者”的宅邸，与之战斗战斗。然后了解到这个事件中，她其实是受害者，而重要的法典其实是危害正常人类的邪典，她是多年前被人陷害接触这个邪典，后身体引发异变，为了保护其他人才独自隐居于此地，玩家在此将面临第一个抉择：带回邪典，或是为其保管，返回谎称失败。第一章至此结束
